# 面板设计记录 · 1.3.0-beta.4

用户需要在同一对话中选定时间段或首尾消息，确认后读取平均 tok/s 与加权缓存命中率，并能明确识别“返回最近响应”“固定此对话到状态栏”“解除固定，自动跟随”三个动作。新版保留现有统计语义，改善操作识别、状态反馈和窄屏布局。

## 方向与取舍

这是本地统计工作区。主动作是确认统计范围，主信息是所选对话的区间平均值。对比页在本地任务目录 `build/ui-redesign/style-explorer.html` 留档，包含原界面、只整理按钮、升级工作区和浅色报告式重塑四项。用户休息期间自主选定“升级”：沿用深色与青绿色，把对话和范围放在左侧，将结果和状态栏管理分开，适合反复选择与比较。

北极星：先知道正在统计哪段对话，再读数，再调整显示方式。系统中文字体负责界面文字；Cascadia Code / Consolas 等宽数字负责计数。背景 `#10171d`、表面 `#19232b`、正文 `#edf3f7`、次要文字 `#b0bec8`、强调 `#83e5c9`；按钮共享填充 `#263943` 与边框 `#6b8592`。记忆点是成对的大号统计读数与对应缓存比例尺。

设计参照官方 [Grafana Stat 文档](https://grafana.com/docs/grafana/latest/visualizations/panels-visualizations/visualizations/stat/) 对读数、名称、单位和聚合的组织，以及 [Chrome DevTools Performance](https://developer.chrome.com/docs/devtools/performance/overview) 的范围分析任务。参照来自文档，没有声称复制其实际画面。

## 控件、状态与布局

- 三个关键动作在默认状态下都有填充与边框，点击高度 44px，主确认按钮 48px；键盘焦点有 3px 轮廓，请求中显示忙碌与禁用状态。
- 自动跟随时显示固定按钮；已固定当前对话时显示解除按钮；固定了另一对话时显示其标题，并允许改固定或解除。每秒读取的绑定元数据反映其他窗口或原生菜单的更改。
- 已确认范围保留快照和确认时间；返回最近响应会清除对应对话的快照。最近完成响应另列，并标明计时口径或历史状态。
- 修改已选消息文字会使该边界失效，必须重新查找并选择。范围错误就近显示，定位到输入框并保留输入和上一次有效结果。
- 左侧查找不会悄悄取消当前对话选择。范围标签支持左右键、Home 和 End。
- 390px 窄屏纵向排列，确认成功后滚动到结果；500px 独立小窗把品牌与刷新并排，保留读数与显示管理。统计公式与服务限制收进可展开说明。

原生“显示状态栏”菜单仅在确实隐藏、最小化或被 DWM 隐藏时可用。已经显示的重复显示请求保留当前对话绑定。该逻辑与浏览器的固定/解除操作分别处理。

## 动效与减法

主确认完成后数字区域以 260ms 渐入和轻微位移反馈；范围标签指示块以 260ms 移动；初次出场分区以 320ms 渐入并轻微错开。系统减少动态效果设置会关闭这些动画。三组实际开始、中间、结束画面及 CSS 状态观测保存在本地 `build/ui-redesign/motion/`，部分中帧已接近动画结束。

删除了首屏重复的支持范围说明、作为小标题的英文文字、页脚重复品牌及重复连接/确认提示；固定当前对话时隐藏重复描述；公式、统计边界与额度数据限制保留在展开说明。对象名称、样本覆盖、确认时间和当前绑定状态均保留。

## 验收范围

全部公开截图来自隔离的模拟日志，没有真实用户消息、ID 或本机认证信息。实际界面证据在本地 `build/ui-redesign/before/`、`after/`；统计值来自现有本地 API。公开截图为 [新版面板](images/dashboard.jpg)。测试计数与平台边界见 [验证记录](VALIDATION.md)。
